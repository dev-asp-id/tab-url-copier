# 🔗 Tab URL Copier

A lightweight, multi-language, and privacy-friendly Chrome extension to instantly copy all open tab URLs in the active window.

[English](#english) | [Bahasa Indonesia](#bahasa-indonesia)

---

## English

### ✨ Features
- **One-click copying** for all active window tab URLs.
- **Custom Delimiters**: Newline (Enter), Semicolon `;`, Comma `,`, Space, or Custom text.
- **Auto Multi-language Support**: Automatically adapts to English or Indonesian based on browser language.
- **100% Offline & Private**: No tracking, no external server calls.

###  🚀 Installation
1. Clone or download this repository:
```bash
git clone https://github.com/dev-asp-id/tab-url-copier.git
```
2. Open Chrome and navigate to chrome://extensions/.
3. Turn on Developer mode (top-right toggle).
4. Click Load unpacked and select the project folder.

## Bahasa Indonesia
### ✨ Fitur
- **Salin Sekali Klik** untuk seluruh URL tab di jendela aktif.
- **Separator Kustom**: Baris Baru (Enter), Titik Koma ;, Koma ,, Spasi, atau teks kustom.
- **Mendukung Multi-bahasa**: Otomatis mengikuti bahasa browser (Inggris/Indonesia).
- **100% Offline & Aman**: Tanpa tracking dan tanpa pengiriman data ke server eksternal.

### 🚀 Cara Install
1. Clone atau download repository ini.
```bash
git clone https://github.com/dev-asp-id/tab-url-copier.git
```
2. Buka Chrome dan ketik chrome://extensions/ di address bar.
3. Aktifkan Developer mode (sakelar kanan atas).
4. Klik Load unpacked lalu pilih folder proyek ini.
